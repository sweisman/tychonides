# Reading catalog claims

| Term | What it establishes |
| --- | --- |
| Exact conversion | A rational representation without rounding, under the stated interpretation of units and components. It does not establish measurement accuracy. |
| Source review | A recorded decision about a reading, structure or interpretation, with the evidence examined and the scope of that decision identified. It does not necessarily mean a human or image review. |
| Independent control agreement | Agreement with a separately entered record in the particular properties compared, such as magnitude, hemisphere, date or clock. It does not make two transcriptions independent observations. |
| Release verification | Successful execution of the enumerated checks implemented by the named verifier version; see [the verification contract](data-workflow.md#what-verification-checks). |
| Analysis eligibility | Acceptance for a named analysis under its declared requirements. Eligibility is not a universal property of a catalog row. |

A calculated coordinate can be useful for studying historical reductions while
remaining unsuitable as a raw reading for a parallax analysis. Null values mean
unestablished or inapplicable information as documented for the field, not zero.
These are documentation terms, not additional database fields.
